# Geographically External Validation of models in ORN Prediction

<a href="https://doi.org/10.5281/zenodo.22683355"><img src="https://zenodo.org/badge/DOI/10.5281/zenodo.22683355.svg" alt="DOI"></a>

## Description
Models derived from https://github.com/AnthonyMatarr/ML-ORN-Pred-update<sup>1</sup> in a single-institutional cohort of 275 patients from Chang-Gung Memorial Hospital in Taiwan are validated on a geographically external cohort of 30 patients from The Johns Hopkins Hospital in the USA.

<sup>1</sup>Matar, A., & Matar, D. (2026). AnthonyMatarr/ML-ORN-Pred-update: v2.0.0 - Updated development of ORN prediction models (Version v2.0.0) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.22683216

## Project layout
- notebooks/: end-to-end machine learning workflows (evaluation, feature importance, net-benefit, etc)

- src/: reusable functions shared across notebooks, including a global seed/random state
